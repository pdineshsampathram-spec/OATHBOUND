## 🛠 Technology Highlights

- **Engine**: Godot 4.7 Forward+ (Metal 3.2 on Apple Silicon)
- **Asset Production**: Blender 5.2.0 (Custom glTF 2.0 hero models)
- **Rendering Architecture**: Data-driven shaders (`sky_cloud_detonation.gdshader`, `upward_branching_eruption.gdshader`, `compression_core.gdshader`)
- **Combat Orchestration**: Server-authoritative multiplayer state machine + 42s cinematic director
